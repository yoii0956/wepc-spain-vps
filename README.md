官网每个套餐都写“双向流量”。这个词的意思是上行和下行合并计算，1TB 双向约等于 500GB 单向。如果按单向 1TB 的心理预期去买，账单或限速提示会来得比想象中早。

## 280ms 的延迟：官方为什么写着“必须加中转”

因为这条线路本来就没做中国方向优化。第三方测评的三网数据：全国平均约 280ms，其中电信 220ms、联通 307ms、移动 262ms，港澳台及东南亚方向约 228ms。回程路由是标准国际路径，电信经荷兰或法国进马德里，联通经德国或法国，移动绕美国或英国。

这个延迟下，直连做视频上传或直播推流基本不可用。官方在套餐描述里写“必须加中转才能正常”，说的就是这件事。实际用法是挂一台香港或落地中转机做前置，西班牙机器负责 IP 环境，中转负责传输。

拿它和本地机房比一下就更清楚：Hostealo 的马德里机房给出的数据是西班牙 ISP 平均 5–15ms，巴黎、米兰、里斯本 25–40ms，法兰克福 25–45ms。同一座城市，用途完全不同。

所以下单前先想清楚：你要的是“西班牙 IP 出现在平台上”，还是“西班牙用户打开网页快”。前者选 WePC 这类住宅 IP 产品，后者选本地机房，两者不重叠。

**西班牙原生 IP 和西班牙机房 IP 差在哪？**

机房 IP 的注册段属于数据中心，平台容易识别为服务器流量；原生 IP 是当地运营商分配的段；住宅 IP 属性最强，来自家庭宽带。Qingtree 在同一个城市把三类分开卖，价格和退款政策都不一样，说明成本和风控表现确实不同。

**需要自己搭中转吗？**

需要。官方在套餐描述里就写了“必须加中转才能正常”。三网直连平均 280ms，不中转做视频和直播体验很差。

**1TB 流量是单向还是双向？**

双向。上行和下行合并计算，单向可用量约 500GB。
